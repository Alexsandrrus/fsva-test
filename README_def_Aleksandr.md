3. Функция detect_and_crop
Эта функция принимает путь к видео, директорию для сохранения обрезанных кадров и размер отступа для обрезки.
Основные шаги внутри функции:
Создание выходной директории: Если директория для сохранения обрезанных кадров не существует, она создается.
Чтение видео: Открывается видеофайл с помощью cv2.VideoCapture. Если видео не может быть открыто, выводится сообщение об ошибке.
Детекция объектов: В цикле считываются кадры из видео, и для каждого кадра выполняется детекция объектов с помощью модели YOLO. Полученные координаты bounding box'ов сохраняются.
Обрезка кадров: Для каждого обнаруженного объекта:
Координаты bounding box'ов корректируются с учетом заданного отступа.
Проверяется корректность координат.
Обрезанный кадр сохраняется в список cropped_frames, а его размеры (ширина и высота) добавляются в список box_sizes.
Возврат результатов: Функция возвращает список обрезанных кадров и размеры bounding box'ов.

4. Функция create_video
Эта функция принимает список обрезанных кадров и путь для сохранения выходного видео.
Основные шаги внутри функции:
Если есть обрезанные кадры, создается объект VideoWriter для записи видео.
Каждый обрезанный кадр записывается в выходное видео.
После завершения записи видео объект VideoWriter закрывается.

5. Основной блок кода
Указываются пути к входному видео, директории для сохранения обрезанных кадров и выходного видео.
Вызывается функция detect_and_crop, которая возвращает обрезанные кадры и размеры bounding box'ов.
Размеры bounding box'ов сохраняются в CSV-файл с помощью библиотеки pandas.
Вызывается функция create_video для создания выходного видео из обрезанных кадров.
В конце выводится сообщение о завершении обработки.
